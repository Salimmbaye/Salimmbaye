##  GRC Portfolio

Four projects covering the full GRC arc — **risk → frameworks → audit → automation** — each built on a fictional fintech and grounded in real standards.

Organization name: NorthStar Lending, Inc.

### 1. [Information Security Risk Assessment (NIST CSF 2.0)](https://github.com/Salimmbaye/risk-assessment-fintech)
> An end-to-end risk assessment: a 14-risk register scored for inherent vs. residual risk and mapped to NIST CSF, delivered as an Excel workbook with live scoring, a risk heatmap, a dashboard, and a quantitative loss model (SLE/ALE) to justify remediation spend — plus a Word report.

`NIST CSF 2.0` · `NIST SP 800-30` · `GLBA` · `quantitative risk` · `Excel`

### 2. [Multi-Framework Controls Crosswalk](https://github.com/Salimmbaye/grc-controls-crosswalk)
> A mapping of 31 control areas across NIST CSF, NIST 800-53, ISO 27001, and CIS Controls, delivered as an Excel workbook with a built-in lookup tool that translates any control into its equivalents in the other frameworks — the "assess once, comply many" principle in practice.

`NIST CSF` · `NIST 800-53` · `ISO/IEC 27001` · `CIS Controls` · `Excel`

### 3. [SOX IT General Controls (ITGC) Assessment](https://github.com/Salimmbaye/sox-itgc-assessment)
> A SOX ITGC assessment for a company preparing for IPO: a 16-control matrix across the four ITGC domains, deficiency classification (material weakness vs. significant deficiency), a segregation-of-duties finding, and an audit-style findings report. Excel workbook + Word report.

`SOX 404` · `ITGC` · `ICFR` · `segregation of duties` · `IT audit` · `Excel`

### 4. [GRC AI Assistant](https://github.com/Salimmbaye/grc-ai-assistant)
> A Python + LLM tool that automates repetitive GRC drafting — writing control descriptions, mapping controls across frameworks, and auto-answering security questionnaires grounded in a company's own policies. Built with responsible-AI guardrails: every answer is cited, flagged if unsupported, and labeled a draft for human review.

`AI / LLM` · `Python` · `security questionnaires` · `responsible AI` · `GRC automation`
